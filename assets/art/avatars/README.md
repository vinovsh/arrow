# Cute profile portraits

Five PNG assets generated with the built-in ImageGen tool, matching the user-approved leaderboard artwork. Original generated alpha is preserved; Android downsamples during image decoding. `ProfileAvatar` reuses these assets across the leaderboard, Home and menu headers. Rival portraits depend on identity rather than rank.

## Prompt set

Shared prompt: Single square mobile game profile avatar; cute glossy dimensional clay toy portrait matching the approved leaderboard reference. Front-facing head and shoulders inside a pastel circular badge with fine white rim. Circle fills 94% of square canvas, tightly centered; actual transparent alpha outside the circle. Soft studio lighting, rounded sculpted features, playful polished 3D render. No UI, text, numbers, extra objects, watermark or other portraits.

- `player.png`: friendly child with dark wavy hair, big brown eyes, happy smile, blue hoodie; yellow circle.
- `cat.png`: lavender kitten with pink inner ears and big shining eyes; lavender circle.
- `ibis.png`: cream peach ibis with long orange beak and happy curved eyes; peach circle.
- `fox.png`: orange fox with white muzzle and one eye winking; mint circle.
- `bird.png`: blue bird with yellow beak, pink cheeks and big shining eyes; sky blue circle.
