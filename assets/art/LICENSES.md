# Art licences

§14 requires every asset shipped in Arrow Escape to be original or licensed for
commercial redistribution, and requires that licence to be recorded. `assets/audio`
keeps that record for sound; this file keeps it for artwork that did not originate
here.

Everything the board draws — arrows, dots, silhouettes, decor — is generated by this
project's own code and has no third-party provenance. There is one exception.

## The coach-mark hand

**`hand-pointer` (solid), Font Awesome Free 6.7.2.** Embedded as path data in
`src/components/GuideHand.tsx`, rotated 25° anticlockwise, filled white and stroked in
the board's ink.

- Copyright 2024 Fonticons, Inc.
- Icons in Font Awesome Free are licensed **CC BY 4.0**
  (<https://fontawesome.com/license/free>), which permits commercial use and
  modification **and requires attribution**.
- Source: <https://unpkg.com/@fortawesome/fontawesome-free@6.7.2/svgs/solid/hand-pointer.svg>

**The attribution is not yet shown anywhere in the app.** CC BY is satisfied by a
credit a user can reach — the usual place is a line in Settings ("Icons by Font
Awesome — CC BY 4.0") or in the store listing. Until one of those ships, this file is
the only record, and that is not enough for release.

If carrying an attribution is not wanted, the two ways out are to swap the icon for an
Apache-2.0 one — Material Symbols `touch_app` is the nearest, though it is a tap
pictogram with a ripple ring rather than a pointing glove — or to commission an
original hand. The component takes a single path, so either is a small change.
